# Анимированные иконки Aviator

Превью: `/design/animated-icons`

Компоненты: `frontend/app/components/animatedIcons.tsx`  
Стили: блок `.ai-*` в `frontend/app/globals.css`  
Подключено в: `SiteHeader`, `MobileMenu` (анимация на hover / focus через `.group`)

## Движения

| Ключ | Где | Анимация |
|---|---|---|
| flights | Авиабилеты | взлёт + лёгкий крен |
| hotels | Отели | здание «дышит», окна мигают |
| tours | Туры | карта раскрывается |
| esim | eSIM | волны сигнала |
| insurance | Страхование | галочка на щите |
| trains | Поезд | состав едет вперёд |
| transfers | Трансферы | машина трогается |
| deals | Акции | процент крутится |
| support | Поддержка | гарнитура «звонит» |
| login | Войти | силуэт увеличивается |
| sun / moon | Тема | лучи вращаются / soft pop |

Форму поиска, глобус и популярные направления не трогаем.
