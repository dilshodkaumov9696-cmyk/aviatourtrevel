Логотипы партнёров (систем бронирования), которых нет в публичных CDN.

Положи сюда файлы с такими именами (PNG или SVG, лучше квадратные, прозрачный фон):

  sirena.png       — Sirena (Sirena-Travel)
  mixvel.png       — Mixvel
  tkp.png          — ТКП (Транспортная Клиринговая Палата)
  citytravel.png   — City Travel

Как только файл появится — он автоматически подхватится в бегущей строке
«Наши партнёры» вместо временного буквенного бейджа.

Имена файлов заданы в:
  frontend/app/components/AirlinesMarquee.tsx  →  массив PARTNERS  →  поле logo
